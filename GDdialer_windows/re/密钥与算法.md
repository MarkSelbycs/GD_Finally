## 1. 门户 body 加密 —— 6 重 DES 级联 ⭐ 核心

### 算法

```
body = hex( E_k3( D_k2( E_k1( E_k6( D_k5( E_k4( 归一化XML 补位 ) ) ) ) ) ) )

分组：8 字节 (DES ECB)
方向：E=加密, D=解密
```

### 6 把密钥

```hex
k1 = 462b2b2a6c69237a
k2 = 535373683f437e2b
k3 = 7c2b216229407b3f
k4 = 23594b7c747a513b
k5 = 536e5f403a54432a
k6 = 2525624a43275a53
```

ASCII 形式（仅作参考，实际按字节使用）：

```
k1 = "F++*li#z"
k2 = "SSsh?C~+"
k3 = "|+!b)@{?"
k4 = "#YK|tzQ;"
k5 = "Sn_@:TC*"
k6 = "%%bJC'ZS"
```

### 级联顺序（重要）

```
E_k4 → D_k5 → E_k6 → E_k1 → D_k2 → E_k3
```

用数组表示（密钥下标, 是否加密）：

```python
CASCADE = [(3, True), (4, False), (5, True), (0, True), (1, False), (2, True)]
```

**解密就是倒序 + 每个操作取反。**

### 前后处理

```
归一化：
  - encoding="UTF-8"  →  encoding="utf-8"
  - 如果开头没有 <?xml，补上 <?xml version="1.0" encoding="utf-8"?>

补位：
  - 末尾补 NUL，长度向上取整到 8 的倍数
  - 最小 64 字节

输出：
  - 小写转大写 hex
```

### 密钥在模块里的位置

```
算法模块（algo_module_46596.bin，49 KB PE）：
  入口              RVA 0x8585
  编码器            RVA 0x6b65        ← 输入明文 XML，输出 hex body
    ├─ 6DES 位变换   RVA 0x5c78 / 0x5e5b
    ├─ 密钥初始化    RVA 0x5a77
    └─ 密钥表        RVA 0x1000c568 + 46，长度 48 字节
  密钥表原始位置：0x1000c568 + 46  取 48 字节 = 上面 6 把密钥
```

## 3. XXTEA 双密钥（算法容器解密用）

下载算法模块时，容器里的载荷是用 XXTEA + LZMA 压的：

```text
容器格式:  001@<32字节hex密钥>$<Algo-ID>]<载荷>
载荷解压:  8 字节前缀 + XXTEA(逐 8 字节) → raw-LZMA → 算法模块 PE
```

### XXTEA 密钥

```text
key1 = |iKFMm;FZjI6oItG        (hex: 7c694b464d6d3b465a6a49366f497447)
key2 = mvm536xR8MJ-5C89        (hex: 6d766d3533367852384d4a2d35433839)
```

### XXTEA 参数（非标准变体）

```text
delta  = 0x9E3779B9
轮数   = 32
加密： v0 += (((v1<<4) ^ (v1>>5)) + (v1^sum) + key[sum & 3]);      sum += delta
       v1 += (((v0<<4) ^ (v0>>5)) + (v0^sum) + key[(sum>>11) & 3])
解密： 反过来
注意： key 只用到 4 个 word（key[sum&3] / key[(sum>>11)&3]）
```

### LZMA 参数

```text
格式 = raw LZMA1（没有头）
lc=3, lp=0, pb=2
```

### 验证

```text
24624 字节（载荷）
  → XXTEA 解密 → 24616 字节
  → raw-LZMA 解压 → 46596 字节，合法 PE（MZ 头）✅
```

> 注意：**每次拨号这个容器密钥和 Algo-ID 都会变**（实测见过 `47305F71...`、
> `6ADD6889...`，Algo-ID 见过 `7F224CA8`、`E9747EF1`），但**算法本体是一样的**。

## 4. 自定义 SPN 流密码（已排除，仅存档）

这个是在 `ESurfingSvr.exe` 里发现的自定义密码。
**经过补丁实验证明它不参与门户 body**（把它的输出改成纯密钥流，body 完全不变），
所以只是存档，不需要实现。

### 两个 S-box（各 256 字节）

```
S-box1: artifacts/spn_sbox1.bin   (文件偏移 0x3b298, VA 0x43be98)
S-box2: artifacts/spn_sbox2.bin   (文件偏移 0x3b398, VA 0x43bf98)
```

### 结构

```
状态：22 个 32 位字（88 字节）
S-box 应用：32 位字的 4 个字节「偶字节查 S-box1、奇字节查 S-box2」
线性扩散： (x<<2|x>>30) ^ x ^ (x<<10|x>>22) ^ (x<<18|x>>14) ^ (x<<24|x>>8)
31 位模加： ((a+b) & 0x7fffffff) + ((a+b) >> 31)
```

### 函数地址（ESurfingSvr.exe，imagebase 0x400000）

| 地址 | 作用 |
| --- | --- |
| `0x426200` | 入口包装 |
| `0x433100` | 初始化（32 轮） |
| `0x4331d0` | 主循环（生成密钥流） |
| `0x432c90` | 线性层 |
| `0x432d80` | 轮函数（S-box） |
| `0x432f50` | 混合 |
| `0x432b70` | 31 位模加 |

完整实现见 [`tools/body_codec.py`](../py/body_codec.py) 的姊妹文件与

## 7. 一句话总结怎么复现

```python
import body_codec
body = body_codec.encode_body(xml)     # XML -> 门户 body
```

或者用 C：

```c
portal_encode_body(xml, out, sizeof(out));
```

只要这 6 把密钥 + 那个级联顺序，就能**完全离线**生成合法报文，
不需要下载算法模块、不需要原版客户端。
